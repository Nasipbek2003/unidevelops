# ТЗ: видео с отзывами студентов для сайта UNIDEVELOPS

## Роль и инструмент
Ты моушн-дизайнер. Собери короткое зацикленное видео из настоящих скриншотов отзывов.

- Монтируй в коде (Remotion или FFmpeg) или в монтажной программе (After Effects, CapCut, DaVinci Resolve).
- Генеративные видеомодели (Sora, Runway, Kling, Veo и подобные) для скриншотов НЕ использовать. Они перерисовывают текст, и отзыв перестаёт быть настоящим.
- Скриншоты вставляются как есть: их можно только обрезать, масштабировать и двигать.

## Входные данные
- Скриншоты отзывов (переписки в WhatsApp, Telegram, Instagram): папка `<ПУТЬ К ПАПКЕ>`.
- Шрифты (Google Fonts, лицензия OFL):
  - Cormorant — заголовки;
  - Golos Text — интерфейс;
  - JetBrains Mono — метки и штамп;
  - Marck Script — рукописные пометки.

## Где будет видео
Видео встанет в секцию «Отзывы» на лендинге о научных работах на заказ (курсовые, дипломы, СРС). Концепция сайта «Рукопись и код»: страница выглядит как рукопись, которую проверил научный руководитель.
- кремовая бумага с зерном;
- тёмно-синие чернила;
- оранжевая «красная ручка» научрука: подчёркивания, галочки, штамп;
- скрепки, стикеры, листы.

Видео должно выглядеть так, будто отзывы распечатали и вклеили в эту рукопись.

Заголовок секции и подписи сайт делает обычным текстом. Поэтому в версии для сайта в кадре нет никакого текста, кроме коротких рукописных пометок и штампа.

## 1. Подготовка скриншотов (до анимации)
1. **Обрезка.** Оставить только сообщения с отзывом. Убрать статус-бар телефона (время, батарея, оператор), шапку чата, клавиатуру, поле ввода.
2. **Анонимность.** Размыть (гауссово размытие от 12 px или пикселизация блоками от 16 px):
   - имена, аватары, номера телефонов, @username;
   - названия вузов, темы работ, ФИО преподавателей;
   - всё остальное, по чему можно узнать студента.
3. **Подлинность:**
   - текст отзыва не менять ни на букву;
   - порядок сообщений не менять;
   - ничего не дописывать;
   - не вырезать куски так, чтобы менялся смысл.
4. **Читаемость:**
   - На телефоне видео показывается шириной около 360 px. Поэтому в кадре шириной 1080 px строчные буквы текста сообщения должны быть высотой не меньше 28 px.
   - Если отзыв длинный, используй медленную прокрутку внутри листа (см. раскадровку) или раздели его на два листа. Мельче не делать.
5. **Тёмные и светлые чаты.** Не перекрашивать. Каждый скриншот лежит на светлом листе-подложке, это само выравнивает разнобой.
6. **Сохранить обработанные скриншоты отдельно** (PNG без потерь): `reviews/01.png`, `02.png`… Сайт покажет их вместо видео тем, у кого отключена анимация.

## 2. Визуальный стиль
**Палитра**, hex строго:
| Роль | Цвет |
|---|---|
| Фон (бумага) | `#F4EEE2` + статичное зерно, шум 3–4 % непрозрачности. Зерно НЕ анимировать: анимированный шум раздувает файл в разы |
| Лист-подложка | `#FBF8F0` |
| Чернила, линии, скрепка | `#1B3650` |
| Тёмный (тени) | `#0F2438` |
| Красная ручка: штрихи, галочки, штамп, пометки | `#F0764F` (только линии и мелкие элементы, большие площади не заливать) |
| Скотч | `#E9E0CE`, 70 % непрозрачности |

**Формы:**
- скругления 0–2 px;
- запрещены градиенты, неон, стекло, блёстки, 3D-перевороты и мягкие «пластиковые» тени.

**Тень** есть только у листа как физического предмета: короткая, вниз-вправо: `0 8px 18px rgba(15,36,56,.14), 0 1px 0 rgba(15,36,56,.10)`.

**Лист-подложка:**
- поля 32–40 px вокруг скриншота;
- тонкая рамка 1 px `#1B3650` с непрозрачностью 25 %;
- наклон у каждого листа свой, от −2° до +2°;
- сверху скрепка (контур, navy) или полоска скотча, чередовать.

**Рукописные пометки:**
- Marck Script, `#F0764F`, 44–56 px;
- только нейтральные: «отзыв 1», «отзыв 2»…, галочка;
- нельзя писать оценки, вузы, «сдал на отлично» и всё, чего нет в самом отзыве.

**Штамп «ЗАЧТЕНО»:**
- прямоугольник с двойной рамкой 3 px `#F0764F`;
- JetBrains Mono 600, 34 px, разрядка 0.12em;
- наклон −8°, непрозрачность 85 %;
- неровные края, как будто краска легла неплотно (маска с шумом).

## 3. Композиция кадра (версия для сайта)
- **Формат:** 1080×1350 (4:5), 30 fps. Этот формат хорошо смотрится и на телефоне, и в колонке на компьютере.
- **Лист со скриншотом:** 78–86 % ширины кадра, по центру, выше центра на 2–3 %.
- **Стопка:** под текущим листом видны края 1–2 предыдущих, сдвинутых на 12–20 px и повёрнутых по-другому. Получается пачка отзывов.
- **Безопасные поля:** 64 px со всех сторон, ничего важного ближе к краю.

## 4. Движение: раскадровка одного отзыва (~4 с)
**Кривая по умолчанию:** `cubic-bezier(0.2, 0.7, 0.2, 1)` — быстрый старт, мягкая посадка. Пружинить (bounce, elastic) может только штамп.

| Время | Что происходит |
|---|---|
| 0,00–0,50 с | Лист кладут на стопку: сдвиг снизу 60 px → 0, поворот на 3° больше итогового → итоговый, масштаб 1,03 → 1,00, непрозрачность 0 → 1 за первые 0,25 с. Тень «садится»: размытие 28 → 18 px |
| 0,35–0,55 с | Скрепка «надевается» сдвигом 10 px сверху, или скотч растягивается слева направо (clip-path) |
| 0,50–3,40 с | **Удержание.** Текст неподвижен минимум 2,5 с. Допускается только очень медленный наезд всего кадра 1,00 → 1,02. Длинный отзыв: вместо наезда ровная прокрутка внутри листа не быстрее 60 px/с, с паузами 0,6 с в начале и в конце. Время удержания = max(2,5 с; число слов ÷ 3) |
| 1,20–1,80 с | Красная ручка рисует галочку на поле листа рядом с последней строкой отзыва, но не поверх текста. Штрих появляется за 0,45 с (stroke-dashoffset) и к концу чуть утолщается, как от нажима |
| 2,20–2,40 с | Штамп «ЗАЧТЕНО» в правом нижнем углу листа. Может заходить на край скриншота не больше чем на 15 % и НИКОГДА не закрывает текст отзыва. Масштаб 1,35 → 0,96 → 1,00 (0,12 + 0,08 с), поворот −14° → −8°. В момент удара весь кадр смещается на 2 px вниз и обратно за 0,1 с |
| 3,50 с | Следующий лист начинает ложиться сверху. Текущий остаётся в стопке |

- **Стопка не растёт бесконечно:** после каждых 3 листов она «смахивается» влево за кадр (сдвиг −110 % за 0,5 с, та же кривая), и стопка начинается заново.
- **Петля:** последний кадр совпадает с первым (первый лист уже лежит, как в начале), стык незаметен.
- **Длительность:** 5–8 отзывов по ~4 с, итого 20–32 с. Если отзывов больше 8, в видео возьми 8 самых содержательных. Остальные отдай отдельными PNG.

**Запрещено:**
- мигание чаще 3 раз в секунду и вспышки;
- тряска камеры (кроме удара штампа на 2 px);
- motion blur по тексту;
- шаблонные переходы (кубы, шторки, звёзды);
- музыка в версии для сайта;
- крупные логотипы мессенджеров.

## 6. Что сдать (для сайта)
1. `reviews.mp4`: H.264 High, yuv420p, CRF 26–28, preset slow, 30 fps, БЕЗ звуковой дорожки, faststart. Цель ≤ 3 МБ.
2. `reviews.webm`: VP9, CRF 34–36, БЕЗ звука. Цель ≤ 2,5 МБ.
3. `reviews-poster.jpg` и `reviews-poster.webp`: кадр, где первый отзыв виден целиком и стоит штамп. 1080×1350, качество 80, ≤ 180 КБ.
4. Папка `reviews/` с обработанными скриншотами (PNG): `01.png`, `02.png`…
5. `reviews.json`: массив вида `{ "file": "01.png", "text": "дословный текст отзыва после анонимизации", "start": 0.0, "end": 4.0 }`. Текст нужен сайту для скринридеров и для показа без видео.
6. Исходник проекта (Remotion/AE/CapCut), чтобы потом можно было добавить новые отзывы.

GIF НЕ делать: такой ролик в GIF весит 20–40 МБ и теряет цвета.

Пример экспорта FFmpeg из мастер-файла:
```
ffmpeg -i master.mov -an -c:v libx264 -profile:v high -pix_fmt yuv420p -crf 27 -preset slow -r 30 -movflags +faststart reviews.mp4
ffmpeg -i master.mov -an -c:v libvpx-vp9 -crf 35 -b:v 0 -row-mt 1 -pix_fmt yuv420p -r 30 reviews.webm
```

## 7. Проверка перед сдачей
- Уменьши видео до 360×450 и посмотри: каждый отзыв читается целиком.
- Нигде не видно имён, аватаров, номеров, @username, вузов и тем работ.
- Текст отзывов совпадает с оригиналами.
- Петля без рывка.
- Штамп и галочки не закрывают текст.
- Размеры файлов в пределах п. 6.
